# My Projects

1 - Unclock
  Role: Game Designer & Level Designer
  
  During the development of Unclock, I worked as both Game Designer and Level Designer.
  
  As a Game Designer, I was responsible for balancing the game systems and gameplay experience, writing and maintaining design documentation, organizing and analyzing playtests, and ensuring clear communication between the different departments involved in the project.
  
  As a Level Designer, I designed the levels, their topology, and the player navigation flow. I focused on how players move through the environments, how spaces guide exploration, and how level structure supports the overall gameplay experience.
